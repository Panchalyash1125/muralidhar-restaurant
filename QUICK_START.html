🚀 Quick Setup Guide

Follow these steps to get your restaurant system running

1

📥 Download & Extract

Extract the Muralidhar-Restaurant-System folder to your Desktop

↓
2

📦 Install Dependencies

Open terminal in project folder and run:

npm install
↓
3

⚙️ Setup Database

Initialize the database with menu items and tables:

npm run setup
↓
4

🚀 Start Server

Launch the server:

npm start
↓
5

✅ Open in Browser

Click or type this URL:

http://localhost:3000/customer/index.html?table=1

💡 Tip: Change table=1 to table=2 for second table

📱 Test on Mobile

Find your computer's IP (run ipconfig on Windows or ifconfig on Mac), then on your phone open:

http://YOUR_IP:3000/customer/index.html?table=1
